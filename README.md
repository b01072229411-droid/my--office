# 몽글 스튜디오 — 실시간 게임형 오피스

가상의 모바일 게임 스튜디오(13명)가 출근하고, 일하고, 결재를 올리는 오피스 시뮬레이션입니다.

```bash
npm install
npm run dev   # http://localhost:3000
```

## 구조
| 파일 | 역할 |
|---|---|
| `app/live-office.css` | LIVE OFFICE UI 스타일 (원본 그대로) |
| `app/globals.css` | 디자인 토큰(`--ink`, `--pink` …) + `.win` `.btn` `.eyebrow` 등 공통 컴포넌트 |
| `lib/office-config.ts` | **커스터마이즈 지점** — 회사명, 방 배치, 부서, 직원, 업무, 일정, 대사, 빠른 지시 |
| `lib/office-sim.ts` | 시뮬레이션 엔진 (시간, 길찾기, 업무 진척, 막힘, 결재, 지시 해석) |
| `components/LiveOffice.tsx` | 화면 (히어로, 컨트롤 바, 월드, 지시창, 결재함, 프로필, 피드, 명단, 일정) |

## 지시창 키워드
- `회의` / `집합` — 전원(또는 `○○팀`) 회의실 집합
- `커피` / `휴식` — 라운지 휴식
- `보고` / `진행` — 팀장들이 진척 보고
- `지원` / `해결` — 막힌 부서 해결
- `집중` / `서둘러` — 60분 동안 진척 1.6배
- `승인` — 맨 위 결재 승인
